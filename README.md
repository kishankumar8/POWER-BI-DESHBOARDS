| Visual                    | Kab Use Karte Hain                       | Example                         |
| ------------------------- | ---------------------------------------- | ------------------------------- |

| 🎯 **Gauge**              | Target vs Achievement                    | Target = ₹10L, Achieved = ₹8L   |
| 🌳 **Treemap**            | Hierarchy aur proportion                 | Sales by Category & Subcategory |
| 🎚️ **Slicer**            | Report filter                            | Year, City, Category            |
